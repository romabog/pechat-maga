# Печать Мага — Подземелья и драконы

Браузерная игра в жанре D&D, где вместо кнопок игрок **чертит магические символы** мышью или пальцем. 70 уровней, каждый со своим существом, семь стражей с собственными механиками.

Вся игра — **один HTML-файл**. Сервер не нужен: двойной щелчок по файлу, и игра запускается.

## Что в репозитории

| Путь | Что это |
|---|---|
| `dist/Печать-Мага-Подземелья.html` | **готовая игра** — её и надо открывать |
| `dist/Уровни-1-70.html` | просмотр всех 70 противников с переключением |
| `src/` | исходники: три с половиной тысячи строк логики и примерно десять тысяч отрисовки |
| `build-single.mjs` | сборка игры в один файл |
| `build-levels.mjs` | сборка переключателя уровней |
| `check-single.mjs` | автопроверка собранного файла |
| `ЧИТАТЬ.md` | подробное описание: механики, стражи, оформление |

## Как играть

Откройте `dist/Печать-Мага-Подземелья.html`.

- **Зажать левую кнопку мыши** и вести по экрану — чертится знак.
- **H** — справка.
- На телефоне — палец вместо мыши.

Каждый символ стоит ману. Правильно выбранный символ отражает или сбивает заклинание врага. У каждого из семи стражей своя механика, которая заставляет менять тактику, а не только следить за здоровьем.

## Почему одним файлом

Игра собрана из ES-модулей, а браузер грузит их только по HTTP. При открытии с диска (`file://`) срабатывает CORS и остаётся белый экран. Поэтому модули склеиваются в один `<script>` внутри страницы — файл работает откуда угодно.

## Пересборка

Нужен Node.js 18 или новее, зависимостей нет.

```bash
node build-single.mjs     # собрать игру
node build-levels.mjs     # собрать переключатель уровней
node check-single.mjs     # проверить, что собранное работает
```

Проверка прогоняет игру в эмуляции браузера на трёх разрешениях — от телефона до десктопа — и сообщает, если что-то сломалось.

## Структура исходников

```
src/
  main.js              игровой цикл, ввод, меню, сохранение
  style.css            оформление
  core/
    sigils.js          распознавание начерченных символов
    combat.js          правила боя
    enemy-ai.js        поведение противников
  data/
    enemies.js         все 70 уровней: кто, с какими параметрами
  render/
    character.js       сборка фигуры целиком
    bodies.js          десять форм тела
    creatures.js       восемь анатомий головы
    bosses.js          семь стражей
    arenas.js          двенадцать подземелий
    spell-fx.js        заклинания и эффекты
    staves.js          посохи

    title-card.js      заставка
  audio/
    audio.js           музыка
    enemy-voice.js     голоса стражей
```

## Как нарисованы существа

Не картинками, а кодом на canvas — поэтому всё масштабируется без потерь и весит ноль килобайт.

**Тела — десять разных форм:** человек в одежде, человек в доспехе, великан, зверь на четырёх лапах, змеиное тело, парящая фигура, масса, шар с глазом, дерево, крылатый.

**Головы — восемь анатомий:** человек, дракон, иллитид, череп, бехолдер, сундук, призрак, зверь. Поверх каждой — своя примета вида: гребень, иней, пламя, ожерелье из щупалец, корона.

**Стражи** нарисованы отдельно, каждый со своим силуэтом, а не общим в другом цвете.

Фигуры строятся от скелета: сначала считаются точки — плечи, локти, кисти, бёдра, колени, стопы, — потом по ним рисуются контуры. Объём даётся градиентами и контровым светом, а не обводкой.

## Лицензия

Игра основана на правилах Dungeons & Dragons, но не содержит текстов правил. Все изображения нарисованы кодом.
